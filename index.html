This is the offical documentation for the Command Line Game Framework (CLGF) library.

About

Command Line Game Framework (CLGF) is a cross platform framework that allows users to program games which run in the command line/prompt. It's a personal library which I created so I could dabble with game dev convepts without having to learn an entire new tool like Unity or Godot. I wanted to release it to the public just in case someone else might find it fun or useful!
