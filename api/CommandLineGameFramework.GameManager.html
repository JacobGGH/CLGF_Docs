ExitCurrentScene()

Exits the current game scene.

public void ExitCurrentScene()

Remarks

The current game scene will not be exited if the result would be that there are no more game scenes left to run (in other words: if the game manager's scene stack would become empty). There must be at least one game scene for the game to run at all times. If the game should exited, use Exit().
