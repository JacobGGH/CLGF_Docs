Namespace CommandLineGameFramework

Classes

CLGF

A framework for programming games that run in the command prompt/command line.

Drawable

The base class for an object that can be drawn to the console screen (i.e. Sprite, Text, etc.).

DrawingBuffer

A buffer which loads and renders Drawable objects (i.e. Sprite, Text) the console screen.

GameManager

A manager which handles running a game (i.e. running the game loop, transitioning game scenes, etc.).

GameScene

The base class for a scene in a game (i.e. menu, main gameplay, etc.). Inherent from this class to create scenes for a game.

Position

A 2-dimensional position (X, Y).

Sprite

A game sprite composed of ASCII art which can be drawn to the console screen.

Text

Text which can be drawn to the console screen.
